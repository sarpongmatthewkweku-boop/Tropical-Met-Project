# Tropical-Met-Project
Investigating And Analysing The Variability Of The Atmosphere Over Ghana From 2015 to 2024.

##Project Overview
This repository analyses geopotential height at 500hPa and 850hPa pressure levels, and rainfall over Twifo Praso, Daboya, Kotei, Ashaiman, Bole, and Ejisu and how they relate to each other.

##Repository Structure
-`geopotential and rainfall.ipynb`: The main Jupyter notebook containing the code and data analysis.
-`requirements.txt`:Python package dependencies.
-`README.md`: Project documentation.
